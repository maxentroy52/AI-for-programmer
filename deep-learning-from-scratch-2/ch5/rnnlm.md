好，这次把 **D 和 H 分开**，并且逐层说清楚**输入输出维度**和**参数形状**。

## 超参数设定

```
N = 2         并行流数（batch size）
T = 10        每条流的序列长度（time size）
总语料长度 = 1000
D = 300       词向量维度（embedding dim）
H = 128       隐藏状态维度（hidden size）
V = 1000      词表大小（vocab size）
```

注意 `D ≠ H`：`D=300`，`H=128`。这完全可以，而且现实中很常见。

## 逐层拆解

### 第 0 层：输入

```
输入: token ids，形状 (N, T) = (2, 10)

  lane 0:  w0,  w1,  ..., w9       ← 每个是一个 id（0~999 的整数）
  lane 1:  w500,w501,...,w509
```

**没有参数**，只是数据。

---

### 第 1 层：TimeEmbedding

**作用**：把每个 id 映射成 D 维向量。

```
输入:   (N, T)      = (2, 10)         整数 id
参数:   embed_W     = (V, D) = (1000, 300)    ← 每一行是一个词的向量
输出:   (N, T, D)   = (2, 10, 300)    每个 id 变成 300 维向量
```

**参数只有 `embed_W`**，形状 `(V, D) = (1000, 300)`。

细节：`embed_W[id]` 直接取出第 id 行，就是那个词的向量。所以 embedding 本质是“查表”，参数就是那张表。

---

### 第 2 层：TimeRNN

**作用**：读入 D 维向量序列，输出 H 维隐藏状态序列。

```
输入:   (N, T, D)   = (2, 10, 300)    每个位置的 300 维向量
参数:   Wx = (D, H) = (300, 128)      输入 → 隐藏 的权重
        Wh = (H, H) = (128, 128)      隐藏 → 隐藏 的权重
        b  = (H,)   = (128,)          偏置
输出:   (N, T, H)   = (2, 10, 128)    每个位置一个 128 维隐藏状态
```

**三个参数**：`Wx (300,128)`、`Wh (128,128)`、`b (128,)`。

关键点：
- 输入维度是 `D=300`，输出维度是 `H=128`，**不一样**。
- `Wx` 负责把 D 维输入投影到 H 维。
- `Wh` 负责把上一步的 H 维隐藏状态投影到 H 维（保持维度）。
- 每个时间步 `t`：`h_t = tanh(x_t @ Wx + h_{t-1} @ Wh + b)`

---

### 第 3 层：TimeAffine

**作用**：把 H 维隐藏状态映射到 V 维词表得分。

```
输入:   (N, T, H)   = (2, 10, 128)    每个位置的 128 维隐藏状态
参数:   W = (H, V)  = (128, 1000)     隐藏 → 词表 的权重
        b = (V,)    = (1000,)         偏置
输出:   (N, T, V)   = (2, 10, 1000)   每个位置对 1000 个词的打分
```

**两个参数**：`W (128,1000)`、`b (1000,)`。

关键点：
- 输入维度 `H=128`，输出维度 `V=1000`。
- 输出是**每个词一个分数**（logit），还没变成概率。

---

### 第 4 层：TimeSoftmaxWithLoss

**作用**：把得分变成概率，和 target 比较，算 loss。

```
输入 1: (N, T, V)   = (2, 10, 1000)    得分（来自 Affine）
输入 2: (N, T)      = (2, 10)          target id（正确答案）
参数:   无
输出:   标量，比如 4.72                loss
```

内部过程：
1. 对每个位置，softmax 把 1000 个得分变成 1000 个概率（加起来 = 1）。
2. 取正确答案那个词的概率，算 `-log`。
3. 把 `N × T = 20` 个位置的 loss 加起来，求平均。

**没有参数**，只是计算 loss。

## 维度变化全表

| 层 | 输入维度 | 输出维度 | 参数（形状） |
|---|---|---|---|
| 输入 | — | `(N, T)` = (2, 10) | 无 |
| TimeEmbedding | `(N, T)` | `(N, T, D)` = (2, 10, 300) | `embed_W (V, D)` = (1000, 300) |
| TimeRNN | `(N, T, D)` | `(N, T, H)` = (2, 10, 128) | `Wx (D, H)`, `Wh (H, H)`, `b (H,)` |
| TimeAffine | `(N, T, H)` | `(N, T, V)` = (2, 10, 1000) | `W (H, V)`, `b (V,)` |
| TimeSoftmaxWithLoss | `(N, T, V)` + `(N, T)` | 标量 | 无 |

## 参数形状速查

```
embed_W  :  (V, D)  = (1000, 300)
rnn_Wx   :  (D, H)  = (300, 128)
rnn_Wh   :  (H, H)  = (128, 128)
rnn_b    :  (H,)    = (128,)
affine_W :  (H, V)  = (128, 1000)
affine_b :  (V,)    = (1000,)
```

注意顺序：`V → D → H → V`，形成了一个“漏斗再展开”的形状。

## 形象图

```
输入 ids:      (2, 10)           整数
              ↓
Embedding:     (2, 10, 300)      V=1000 → D=300   每个 id 膨胀成 300 维
              ↓
RNN:           (2, 10, 128)      D=300 → H=128    压缩成 128 维状态
              ↓
Affine:        (2, 10, 1000)     H=128 → V=1000   展回词表空间
              ↓
Softmax+Loss:  标量              和 target 比较
```

## 每个位置的“纵向切片”

聚焦 lane 1, t=3 一个位置：

```
id:          w503                      标量
             ↓ Embedding
向量:        [0.12, -0.05, ..., 0.08]  300 维  ← D
             ↓ RNN
隐藏状态:    [0.4, -0.2, ..., 0.6]     128 维  ← H
             ↓ Affine
得分:        [2.1, -1.3, ..., 3.7]     1000 维 ← V
             ↓ Softmax
概率:        [0.02, 0.001, ..., 0.15]  1000 维
             ↓ 取正确答案的概率，-log
loss:        单个位置的损失
```

## 为什么 D 和 H 可以不同

- **D（词向量维度）** 是“词的表示有多宽”，由你决定。
- **H（隐藏状态维度）** 是“模型记忆有多宽”，也由你决定。
- 两者没有强制关系，可以 D=300, H=128；也可以 D=128, H=256；也可以相等。

`Wx (D, H)` 就是那个“把 D 维输入投影到 H 维隐藏”的桥梁。正因为有它，D 和 H 才能不同。

## 一句话总结

> `V` 是词表大小，`D` 是词向量维度，`H` 是隐藏状态维度。Embedding 把 `(N, T)` 的 id 变成 `(N, T, D)` 的向量；RNN 把它变成 `(N, T, H)` 的隐藏状态；Affine 把它变成 `(N, T, V)` 的词表得分；softmax+loss 把它变成标量 loss。参数分别住在各自层里，形状由 `V, D, H` 决定，互不强制相等。
