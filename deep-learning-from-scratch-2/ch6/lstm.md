好，用 `N = 1` 讲，最直观。

## 超参数（沿用之前的例子）

```
N = 1          并行流数（只有 1 条流）
D = 300        词向量维度
H = 128        隐藏状态维度
```

## forward 的三个输入

```python
def forward(self, x, h_prev, c_prev):
```

### 1. `x` —— 当前时间步的输入

```
x: (N, D) = (1, 300)
```

含义：**当前时刻，这条流读进来的词向量**。是一个 300 维的行向量：

```
x = [[0.12, -0.05, 0.33, ..., 0.08]]     ← 1 行，300 列
```

注意：这是**已经过了 Embedding** 的向量，不是 id。id 在上一层就变成向量了。

### 2. `h_prev` —— 上一步的隐藏状态

```
h_prev: (N, H) = (1, 128)
```

含义：**上一步传下来的「短期记忆 / 输出」**。128 维：

```
h_prev = [[0.5, -0.3, 0.7, ..., 0.1]]     ← 1 行，128 列
```

第一个时间步时，它通常是全 0（还没有历史）。

### 3. `c_prev` —— 上一步的记忆单元

```
c_prev: (N, H) = (1, 128)
```

含义：**上一步传下来的「长期记忆」**。也是 128 维：

```
c_prev = [[0.2, -0.1, 0.4, ..., -0.3]]    ← 1 行，128 列
```

这是 LSTM 特有的——普通 RNN 只有 `h`，LSTM 多了一条 `c` 专门存长期记忆。

## 为什么 `h_prev` 和 `c_prev` 都是 `(N, H)`

因为它们都是**每条流一个 H 维向量**：

- `h`：当前时刻对外输出的隐藏状态
- `c`：内部记忆，不直接对外，但跨时间步传递

两者维度相同（都是 `H`），形状也相同（`(N, H)`），但角色不同：

| | 作用 | 是否对外输出 |
|---|---|---|
| `h` | 短期记忆 / 输出 | 是（传给下一层，也传给下一时刻） |
| `c` | 长期记忆 | 否（只在 LSTM 内部循环传递） |

## 三个输入的形状汇总

```
x:       (N, D) = (1, 300)    当前输入向量
h_prev:  (N, H) = (1, 128)    上一步隐藏状态
c_prev:  (N, H) = (1, 128)    上一步记忆单元
```

## 在 forward 里怎么用

```python
def forward(self, x, h_prev, c_prev):
    Wx, Wh, b = self.params
    N, H = h_prev.shape              # N=1, H=128

    A = np.dot(x, Wx) + np.dot(h_prev, Wh) + b
    #   (1,300)@(300,512) = (1,512)
    # + (1,128)@(128,512) = (1,512)
    # + (512,) 广播        = (1,512)
    # → A: (1, 512)
    ...
```

`A` 是 `(1, 512)`——一条流、四个门拼在一起。

## 切出来的四个部分

```
f = A[:, :128]       → (1, 128)   遗忘门
g = A[:, 128:256]    → (1, 128)   候选记忆
i = A[:, 256:384]    → (1, 128)   输入门
o = A[:, 384:512]    → (1, 128)   输出门
```

每个都是 `(1, 128)`——一条流、128 维。

## 输出

```python
return h_next, c_next
```

```
h_next: (N, H) = (1, 128)    新的隐藏状态，传给下一时刻 / 下一层
c_next: (N, H) = (1, 128)    新的记忆单元，只传给下一时刻
```

## 整个流程一张图（N=1）

```
x       (1, 300)  ─┐
h_prev  (1, 128)  ─┼──► A (1, 512) ──► slice ──► f,g,i,o (各 1,128)
c_prev  (1, 128)  ─┘                              │
                                                  ▼
                                    c_next = f*c_prev + g*i   (1,128)
                                    h_next = o * tanh(c_next) (1,128)
                                                  │
                                                  ▼
                                       return h_next, c_next
```

## 和普通 RNN 对比

| | 普通 RNN | LSTM |
|---|---|---|
| 输入 | `x, h_prev` | `x, h_prev, c_prev` |
| 状态 | 只有 `h` | `h` 和 `c` 两条 |
| 输出 | `h_next` | `h_next, c_next` |
| 内部 | 一次 tanh | 三个门 + 候选，再组合 |

LSTM 比 RNN 多了一条 `c` 的状态线，这是它能记住长期信息的关键。

## 一句话总结

> `N=1` 时：`x` 是 `(1, 300)` 的当前输入向量，`h_prev` 是 `(1, 128)` 的短期记忆，`c_prev` 是 `(1, 128)` 的长期记忆。三者算出一个 `(1, 512)` 的大矩阵 `A`，切成 `f/g/i/o` 各 `(1, 128)`，组合出新的 `h_next` 和 `c_next`，都是 `(1, 128)`。LSTM 比普通 RNN 多了一条 `c` 状态线。
