## 输入（Add & Norm 的输出）

```
x (3, 8) =
  t0: [-1.342, -1.342, -0.447, -0.447, 0.447, 0.447, 1.342, 1.342]
  t1: [-1.475, -1.180, -0.590, -0.295, 0.295, 0.590, 1.180, 1.475]
  t2: [-1.589, -0.953, -0.742, -0.106, 0.106, 0.742, 0.953, 1.589]
```

## FFN 结构

```
FFN(x) = ReLU(x @ W1 + b1) @ W2 + b2

W1: (D, 4D) = (8, 32)
b1: (4D,) = (32,)
W2: (4D, D) = (32, 8)
b2: (D,) = (8,)
```

**每个位置独立**——`(3, 8)` 的每一行各自过 FFN，**共享 `W1/W2`，但各自算**。

为了演示简单，假设：
- `W1` 是「前 8 维复制 4 份」的矩阵（升维），即 `W1 = [I; I; I; I]`，`(8, 32)`。
- `b1 = 0`，`b2 = 0`。
- `W2` 是「32 维取平均前 4 份」的矩阵（降维），即 `W2[i, j] = 0.25`（每个输出是 4 个输入的均值）。

**这样升维 = 复制 4 份，降维 = 取平均**——简单、可手算。

## 位置 0：`x[0] = [-1.342, -1.342, -0.447, -0.447, 0.447, 0.447, 1.342, 1.342]`

### 第 1 步：升维 `h = x @ W1 + b1`

`W1` 是「复制 4 份」，所以 `h` 是 `x[0]` 重复 4 次，`(32,)`：

```
h[0] = [-1.342, -1.342, -0.447, -0.447, 0.447, 0.447, 1.342, 1.342,

```

### 第 2 步：ReLU `h = max(0, h)`

**负数变 0，正数不变：**

```
h[0] = [0, 0, 0, 0, 0.447, 0.447, 1.342, 1.342,
        0, 0, 0, 0, 0.447, 0.447, 1.342, 1.342,
        0, 0, 0, 0, 0.447, 0.447, 1.342, 1.342,
        0, 0, 0, 0, 0.447, 0.447, 1.342, 1.342]
```

### 第 3 步：降维 `out = h @ W2 + b2`

`W2` 是「每 4 个取平均」，所以每个输出是 `h` 对应 4 个位置的均值：

```
out[0][0] = (h[0]+h[8]+h[16]+h[24]) / 4
          = (0+0+0+0) / 4 = 0

out[0][1] = (h[1]+h[9]+h[17]+h[25]) / 4 = 0

          = (0.447+0.447+0.447+0.447) / 4 = 0.447

out[0][5] = (h[5]+h[13]+h[21]+h[29]) / 4 = 0.447

out[0][6] = (h[6]+h[14]+h[22]+h[30]) / 4
          = (1.342+1.342+1.342+1.342) / 4 = 1.342

out[0][7] = (h[7]+h[15]+h[23]+h[31]) / 4 = 1.342
```

**`out[0] = [0, 0, 0, 0, 0.447, 0.447, 1.342, 1.342]`**

**效果**：ReLU 把负数变成 0，正数保留。`out[0]` 是 `x[0]` 过 ReLU 后的结果（因为升维/降维是「复制再平均」，不改变值）。

## 观察

**ReLU 把负数全变成 0**——前 4 维（原来是负数）都变成 0，后 4 维（正数）保留。

**升维/降维是「复制再平均」**——不改变值，只是「过一遍 ReLU」。**实际 `W1/W2` 是训练学出来的随机矩阵**，会做「非平凡的升维/降维变换」，不只是复制/平均。

## 完整流程

```
x (3, 8)  [Add & Norm 输出]
  │
  ▼ 升维: x @ W1 + b1 → (3, 32)
  │
  ▼ ReLU: max(0, ...) → (3, 32)
  │
  ▼ 降维: @ W2 + b2 → (3, 8)
out (3, 8)  [FFN 输出]
```

## 一句话

> **FFN：每个位置独立，`x (8) → 升维 (32) → ReLU → 降维 (8)`。** 这个例子里升维/降维是「复制/平均」，所以 `out` 就是 `x` 过 ReLU 的结果（负数变 0）。**实际 `W1/W2` 是训练学出来的，会做非平凡变换。** **每个位置共享 `W1/W2`，但各自算。**

## 顺带：FFN 之后还有 Add & Norm

**FFN 不是最后一个模块**——它后面还有一层 `Add & Norm`：

```
out = LayerNorm(x + FFN(x))
```

**`x` 是 FFN 的输入**（Add & Norm 的输出），`FFN(x)` 是 FFN 输出。**残差 + 归一化**，和 attention 后面的一样。

**完整 Transformer encoder 层：**

```
x → MHA → Add&Norm → FFN → Add&Norm → out
```

**两个 sublayer（MHA、FFN），各包一层 Add & Norm。**
