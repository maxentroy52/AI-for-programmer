## 两条样本

```
样本 A: "85+732 _817 "
样本 B: "361+407_768 "
```

**注意：两条都是等长的**（问题 6 字符，答案 5 字符）。

## 第一步：读文件，按 `_` 切分

```python
for line in open(file_path, 'r'):
    idx = line.find('_')
    questions.append(line[:idx])
    answers.append(line[idx:-1])
```

`line` 是整行（含末尾换行 `\n`）：

| 样本 | line | idx（`_` 位置） | question = line[:idx] | answer = line[idx:-1] |
|---|---|---|---|---|
| A | `"85+732 _817 \n"` | 6 | `"85+732 "` | `"_817 "` |
| B | `"361+407_768 \n"` | 7 | `"361+407"` | `"_768 "` |

**注意：**

- A 的问题 `line[:6]` = `"85+732 "`（6 字符，含末尾空格）。
- B 的问题 `line[:7]` = `"361+407"`（7 字符）。

**等等——长度不一样？** A 问题 6 字符，B 问题 7 字符。这就会出问题。

**但真实的 `addition.txt` 是对齐的**，你之前贴的样本显示所有问题等长。假设这里两条都是 7 字符问题、5 字符答案（对齐后的）：

```
样本 A: "85+732  _817 "      问题 "85+732  " (7)  答案 "_817 " (5)
样本 B: "361+407 _768 "      问题 "361+407 " (7)  答案 "_768 " (5)
```

用这个等长版本继续。

## 第二步：建词表

```python
for i in range(len(questions)):
    _update_vocab(questions[i])
    _update_vocab(answers[i])
```

遍历所有问题和答案的字符，按第一次出现顺序分配 id：

```
'8' → 0
'5' → 1
'+' → 2
'7' → 3
'3' → 4
'2' → 5
' ' → 6
'_' → 7
'1' → 8
'6' → 9
'0' → 10
'4' → 11
...
```

（假设顺序如此；实际取决于遍历顺序。）

## 第三步：建 id 矩阵

```python
x = numpy.zeros((2, len(questions[0])), dtype=int)   # (2, 7)
t = numpy.zeros((2, len(answers[0])),   dtype=int)   # (2, 5)
```

宽度：问题 7（第一个问题长度），答案 5（第一个答案长度）。

**问题转 id：**

```python
x[0] = [char_to_id[c] for c in "85+732  "]
     = [0, 1, 2, 3, 4, 5, 6]        # '8','5','+','7','3','2',' '

x[1] = [char_to_id[c] for c in "361+407 "]
     = [4, 9, 8, 2, 11, 10, 3]      # '3','6','1','+','4','0','7'... 

（'3'=4, '6'=9, '1'=8, '+'=2, '4'=11, '0'=10, '7'=3, ' '=6）
实际是 [4, 9, 8, 2, 11, 10, 3] 或按你的词表顺序，这里只是示意。
```

**答案转 id：**

```python
t[0] = [char_to_id[c] for c in "_817 "]
     = [7, 0, 8, 3, 6]              # '_','8','1','7',' '

t[1] = [char_to_id[c] for c in "_768 "]
     = [7, 3, 9, 0, 6]              # '_','7','6','8',' '
```

## 第四步：打乱

```python
indices = numpy.arange(2)          # [0, 1]
numpy.random.seed(1984)
numpy.random.shuffle(indices)      # 假设变成 [1, 0]

x = x[indices]                     # x[1], x[0]
t = t[indices]                     # t[1], t[0]
```

打乱后：

```
x = [x[1], x[0]]     # 先 B 后 A
t = [t[1], t[0]]
```

**问题和答案用同一个 `indices`，配对不变。**

## 第五步：90/10 切分

```python
split_at = len(x) - len(x) // 10 = 2 - 0 = 2
```

`2 // 10 = 0`，所以 `split_at = 2`。

```python
x_train = x[:2]     # 全部 2 个
x_test  = x[2:]     # 空
t_train = t[:2]
t_test  = t[2:]
```

**只有 2 个样本，10% 是 0 个，所以全进训练集，测试集为空。**

## 第六步：返回

```python
return (x_train, t_train), (x_test, t_test)
```

```
x_train: (2, 7)    问题 id
t_train: (2, 5)    答案 id
x_test:  (0, 7)    空
t_test:  (0, 5)    空
```

## 完整数据流

```
文件行:
  "85+732  _817 \n"
  "361+407 _768 \n"
       │
       ▼ 按 '_' 切分
questions: ["85+732  ", "361+407 "]
answers:   ["_817 ",    "_768 "]
       │
       ▼ 建词表（字符 → id）
char_to_id: {'8':0, '5':1, '+':2, '7':3, '3':4, '2':5, ' ':6, '_':7, '1':8, '6':9, '0':10, '4':11, ...}
       │
       ▼ 转 id 矩阵
x = [[0,1,2,3,4,5,6],       # "85+732  "
     [4,9,8,2,11,10,3]]     # "361+407 "
t = [[7,0,8,3,6],           # "_817 "
     [7,3,9,0,6]]           # "_768 "
       │
       ▼ 打乱
x = [x[1], x[0]]
t = [t[1], t[0]]
       │
       ▼ 90/10 切分
x_train = 全部, x_test = 空
       │
       ▼ 返回
(x_train, t_train), (x_test, t_test)
```

## 进 seq2seq 后

```python
xs = x_train          # (2, 7) 问题
ts = t_train          # (2, 5) 答案

decoder_xs = ts[:, :-1]    # (2, 4) 答案去掉最后
decoder_ts = ts[:, 1:]     # (2, 4) 答案去掉第一
```

样本 A 的：

```
ts[0]       = [7, 0, 8, 3, 6]       # "_817 "
decoder_xs[0] = [7, 0, 8, 3]        # "_817"
decoder_ts[0] = [0, 8, 3, 6]        # "817 "
```

逐位置：

```
输入 '_'(7) → 标签 '8'(0)
输入 '8'(0) → 标签 '1'(8)
输入 '1'(8) → 标签 '7'(3)
输入 '7'(3) → 标签 ' '(6)
```

**这就是 teacher forcing：输入真实答案前缀，预测下一个字符。**

## 一句话

> 两条等长样本 → 按 `_` 切分 → 建词表 → 转 id 矩阵 `(2,7)` 和 `(2,5)` → 打乱（同一 `indices`）→ 90/10 切分（2 个样本时全进训练）→ 返回 `(x_train, t_train), (x_test, t_test)`。**等长是关键：`len(questions[0])` 作宽度，所有样本必须等长，否则赋值崩。** 进 seq2seq 后，`ts[:, :-1]` 和 `ts[:, 1:]` 做 teacher forcing 的错位。

## 顺带：为什么两条样本测试集是空

`len(x)//10 = 2//10 = 0`。**样本太少，10% 取整为 0。** 真实数据集（几万条）不会有这个问题。**2 条只是演示用。**
